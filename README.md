# YMixin

English | [中文](README_zh.md)

YMixin is a bytecode instrumentation tool similar to Mixin. Unlike Mixin, YMixin is more lightweight and the bytecode it generates can be used for hot-swapping.

You can check the [wiki](https://github.com/yapeteam/YMixin/wiki)

Example code is available at https://github.com/yapeteam/YMixin/tree/master/src/test/java/cn/yapeteam/ymixin/example

# Usage

## 1. Initialization

```java
public static void init(ClassProvider provider, ClassBytesProvider bytesProvider, @Nullable Logger logger);
```

This is the `init` method in `YMixin.class`, which means you need to initialize it before use.

You can initialize it like this:

First, these are 3 functional interfaces, taking three parameters:

|              Parameter name              |            Purpose             |
|:---------------------------------------:|:------------------------------:|
|       ClassProvider provider            |  Callback to obtain the target class  |
|   ClassBytesProvider bytesProvider      | Callback to obtain the target class bytecode |
|       @Nullable Logger logger           |       Callback for logging     |

If you have no special needs, you can follow the approach in the example:

```java
YMixin.init(
  clazz -> {
    try {
      return Class.forName(clazz);
    } catch (ClassNotFoundException e) {
      return null;
    }
  }, clazz -> {
    try {
      return readStream(Objects.requireNonNull(Main.class.getResourceAsStream("/" + clazz.getName().replace(".", "/") + ".class")));
    } catch (Exception e) {
      return null;
    }
  }, null,
  null,
  null
);
```

## 2. Choosing a mapping table (optional)

With a mapping table, you can dynamically modify obfuscated classes. If there is no obfuscation, you can skip this step.

Pass `mapping_reader` and `mapping_content` during YMixin initialization to set up your mapping.

```java
YMixin.init(
  clazz -> {
    try {
      return Class.forName(clazz);
    } catch (ClassNotFoundException e) {
      return null;
    }
  }, clazz -> {
    try {
      return readStream(Objects.requireNonNull(Main.class.getResourceAsStream("/" + clazz.getName().replace(".", "/") + ".class")));
    } catch (Exception e) {
      return null;
    }
  }, null,
  <mapping_reader>,
  <mapping_content>
);
```

If `<mapping_reader>` is not provided, YMixin will use `SrgMappingReader` by default.

If your obfuscation mapping file format is not supported, you can write your own parser by implementing `cn.yapeteam.ymixin.utils.Mapper.IMappingReader`.

## 3. Creating a transformer

Use the `addMixin(class)` method on a newly created *Transformer* instance to add your injected code.

```
byte[] bytes = transformer.transform().get("your.class.name");
```

The generated bytecode can be loaded through a custom ClassLoader, or hot-swapped by calling JVMTI.
